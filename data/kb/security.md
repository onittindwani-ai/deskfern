# Security overview

## Encryption

Notes are encrypted in transit with TLS and at rest. Passwords are stored as salted hashes. Fieldnote staff can only open a workspace with the owner's written permission for a support case.

## Testing

We run an outside security test once a year. Report a problem to security@fieldnote.example.test.
